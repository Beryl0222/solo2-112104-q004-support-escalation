# 多轮客服对话的承诺边界与升级处置

本项目整理企业支持团队把跨渠道对话交给不同班次处理。客户在一轮对话里谈及两个订单，后续用“这个”指代其中一个；只做句级意图分类会把退款请求、物流咨询和已作出的客服承诺错误合并，造成接班人员重复承诺或遗漏升级。

演练资料位于 `data/support.json`，内容为合成记录，保留不同来源的原始表述和修订关系。项目环境使用 Python 3.11 标准库。

当前资料检查入口为 `python3 -m unittest discover -s tests -v`。检查仅确认 JSON 文件可以读取、记录字段完整且每条原文存在，不会生成业务判断。尚无面向使用者的业务命令。
